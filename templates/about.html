About the Project

A simple Trekking Management Application built for MAD1.

Project Overview

The Trekking Management Application is a web-based system for managing trekking activities. It helps keep trek details, staff assignments, user bookings, and booking history in one place.

The project uses Flask for backend routing, SQLite for storing data, SQLAlchemy for database handling, Jinja templates for pages, and Bootstrap for simple responsive UI.

Main Roles

Admin

Admin manages treks, users, staff, staff approval, and booking records.

Trek Staff

Staff manages only assigned treks and views participants for those treks.

User / Trekker

Users can register, browse open treks, book treks, and view their history.

Basic Workflow

Admin creates and manages treks.

Admin approves trek staff and assigns staff to treks.

Users browse open treks and make bookings.

Staff manages assigned treks and participant details.

Booking and trek history is stored for future reference.
